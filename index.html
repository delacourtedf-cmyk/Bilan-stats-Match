Bilan volley à partir de fichiers DVW

Version 2026-10-25.8 iPhone / iPad : bouton « Partager », puis « Sur l'écran d'accueil ». Nouvelle version disponible. Prête à marcher sans Internet.

Les fichiers restent sur cet ordinateur : la page les lit sans les envoyer.

Choisir ou déposer les fichiers .dvw
Un fichier = un match. Plusieurs fichiers = bilan cumulé.
Facultatif. La page associe chaque vidéo à son match par le nom du fichier. La vidéo s'ouvre alors dans le bilan sans autre clic. Rien n'est envoyé sur Internet.
